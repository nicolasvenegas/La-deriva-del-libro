# La deriva del libro

Un proyecto editorial por ediciones. Este `main` aloja el **índice/hub** que enlaza cada edición.

Ramas:
- `main` → hub (raíz del sitio publicado)
- `Edición-1` → sitio de la primera edición (`/edicion-1/`)
- `Edición-2` → landing de la segunda edición (`/edicion-2/`)

Sitio publicado (workflow `Deploy Pages`): `https://nicolasvenegas.github.io/La-deriva-del-libro/`
